# Changelog

## 1.1.0

### Added
- Added `InventoryItemsOnly` to limit drop protection to inventory-sized items while letting larger items drop normally. The option is off by default and works with `RequireModifier`

## 1.0.0

### Initial Release
- Stops the pick up/interact button from dropping what you're holding
- Optionally, turn on `RequireModifier` to drop while holding a modifier key (default `LeftAlt`)
